The six-gate method

Every Halstead & Byrne engagement runs through the same six gates. Not as ceremony — as a way to keep a year-long systems build from quietly becoming a year of drift.

Most design-system programs don't fail on craft. They fail on drift: tokens fork, the library diverges from the product, governance becomes a meeting nobody schedules. Our method makes drift expensive to hide and cheap to fix, because the same tracker your leadership reads is the one the engineers stand up in.

paper v1 · 2019 v2.0 · 2021 v3.4 · 2024 v4.2 · current

Gate 1 — Tokens

A system begins as arithmetic, not pictures. Before any component exists we agree the type scale, the spacing ladder, the semantic colors, and — critically — the decision log that records why each value is what it is. Gate 1 passes when the tokens build clean and every value has a written reason.

The tokens live as code. To see one, open a terminal and run:

# gate 1 · build and diff the token set
$ pdm run tokens --build
→ 214 values ok · 0 undocumented · drift 0.00%
$ pdm run tokens --diff --against=main

Reviewers sign by running G1 in the tracker command palette, or ⌘ K then “gate sign”. A signature is a person, a date, and the exact artifact hash — not a meeting.

"The tokens are the contract. Everything after gate 1 is just the contract made visible." — internal method memo, 2021

Gate 2 — Library

Ninety-six components is the median we ship, and no component enters the library until it can be built only from tokens. Library reviews are boring on purpose: same order every time — anatomy, states, density, motion, a11y, deletion.

Gate 3 — Rails

"Rails" is what your product teams ride: the layouts, flows, and patterns the library composes into. This is where most engagements spend their run time. Rails pass when three product teams, who never spoke to each other, build the same surface and agree it took less time than before.

What a gate costs — and what it buys

A gate is a scheduled readout, a signed rubric sheet, and one number in the tracker. Skipping one is allowed exactly once per engagement, in writing, with an expiry. The audit below is the live coverage from the Meridian run at gate 4.
