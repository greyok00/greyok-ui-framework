layouts

Twenty layout archetypes

A layout is spacing and structure only: it re-orders the home blocks a page already has and never paints anything. Every preview here is rendered in the neutral token set so structure is the only variable. A theme is an overlay you apply to any layout. Pin one with <html data-layout="bento-dashboard"> after including layouts.css. Every theme matches every layout.
